# Antisèche — commandes de base

| But | Commande |
|---|---|
| Lister les fichiers | `ls` · tout voir : `ls -a` · détails : `ls -l` |
| Changer de dossier | `cd Documents` · remonter : `cd ..` · maison : `cd` |
| Afficher un fichier | `cat fichier.txt` |
| Chercher un motif | `grep motif fichier` · sans la casse : `grep -i motif fichier` |
| Décoder du base64 | `echo <texte> | base64 -d` |
| Lire un binaire | `file prog` · `strings prog` |
| Passer root | `sudo <commande>` (demande TON mot de passe) |
| Métadonnées image | `exiftool photo.svg` |

Astuce : la touche **Tab** complète, **↑** rappelle la dernière commande, `man <cmd>` donne le détail.
